# 원저작물 라이선스

소스 아카이브는 각 프로젝트 원본의 라이선스 고지와 파일별 저작권을 포함한다. 편의를 위해 대표 라이선스를 이 디렉터리에도 복사했다. 배포 시 원본 소스와 고지를 함께 유지한다.

- `libfprint-COPYING`: libfprint 포크의 COPYING. 원본 전체는 `sources/fingerprint/`.
- `libinput-COPYING`: libinput의 COPYING. 원본 전체는 `sources/drag/`.
- `enable-3fg-drag-LICENSE`: shim의 LICENSE. 원본 전체는 `sources/drag/`.
- `mutter-COPYING`, `mutter-debian-copyright`: Mutter의 라이선스와 Ubuntu/Debian 파일별 고지. 원본 전체는 `sources/mutter/`.

로컬 패치는 해당 원본 프로젝트의 라이선스 조건 아래 제공한다. 외부 코드에 일괄적으로 별도 라이선스를 덧씌우지 않는다. 이 보관소의 관리 도구는 개인 시스템 재현을 위해 작성했다.
