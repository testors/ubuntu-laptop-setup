# 보관소 검증 결과

검증 날짜: 2026-09-19. 대상: Ubuntu 26.04 amd64, GNOME 50, EGIS `1c7a:05b1` 센서가 있는 기존 노트북.

## 이번 보관 작업에서 수행한 검사

| 검사 | 결과 |
|---|---|
| 소스·패치·원래 바이너리·라이선스 SHA-256 | 31개 파일 일치 |
| 지문/드래그 기존 설치 파일과 보관본 비교 | 3개 공유 라이브러리 해시 일치 |
| 기존 Mutter 설치 버전 | 패키지 4개 모두 `50.1-0ubuntu2.4+keymapfix1` |
| 세 구성 설치 및 지문/드래그 비활성화 모의 실행 | 성공; 실제 설정·서비스 변경 없음 |
| Mutter 공식 패키지 원복 모의 실행 | 4개 교체, 패키지 삭제 0개 |
| 다른 디렉터리로 전체 복사 후 실행 | 공백 포함 경로, 다른 작업 디렉터리에서 해시 검사·드래그 모의 실행 성공 |
| 설치 도구의 보호 장치 자동 시험 | 11개 통과 |
| fingerprint 원본 추출 → 새 빌드 → 시험 → 산출물 생성 | 성공, 라이브러리 단위 시험 그룹 4개 통과 |
| drag 원본 추출 → 패치 → 새 빌드 → 시험 → 산출물 생성 | 성공, 일반 사용자 시험 그룹 9개 통과 |
| 새 fingerprint/drag 산출물의 ABI 연결 검사 | fprintd / GNOME 대상 `ldd -r`, 누락 라이브러리·미해결 심볼 없음 |
| 새 산출물의 설치 모의 실행 | 두 구성 모두 성공 |
| Mutter 원본 추출·Ubuntu 기존 패치 30개·로컬 패치 적용 | 성공, 적용 fuzz 0 |
| Mutter 빌드 의존성 검사 | 통과 |
| Python 문법 및 두 shell 진입점 구문 검사 | 통과 |

보호 장치 시험은 손상된 해시, 디렉터리 밖 파일 참조, 다른 OS/아키텍처, 알 수 없는 기존 설정, 드라이버 ABI 검사 실패, 서비스 reload 실패 때의 설정 복원, 반복 적용·비활성화, 최신 Mutter 다운그레이드 차단, libinput 기준 버전 변경, 이미 적용된 패치와 충돌 구분을 포함한다. 라이브러리를 교체해도 기존 파일을 열어 둔 프로세스가 읽던 내용은 유지되는지 확인했다. 실제 설치 동작은 임시 디렉터리와 모의 서비스에서 시험했다.

이번 drag 재빌드 환경에는 시스템 `python3-pytest`/`check`가 없었다. pytest와 의존 패키지를 공식 APT에서 받아 작업 폴더에만 추출하고 시험했다. 선택적 litest 자체 시험은 없어서 9개 그룹을 실행했다. 배포 레시피의 `deps drag`는 두 의존성의 설치 명령을 안내한다. fingerprint에서는 사용하지 않는 hwdb/AppStream 데이터 시험 문제를 확인해 라이브러리 단위 시험 범위를 명시했다. 자세한 내용은 [빌드 안내](building.md)에 있다.

새 빌드 파일은 컴파일 경로·옵션 차이로 기존 설치 파일과 해시가 달라질 수 있다. 보관소 루트 `artifacts/`는 실제 장치 검증을 마친 기존 바이너리를 유지한다. 새 파일을 현재 시스템에 설치하거나 실제 지문/드래그를 다시 시험하지 않았다.

## 이전 설치에서 이미 수행한 검사

- 지문: 실제 등록, 일치 인증, 미등록 손가락 거부, fprintd 재시작 후 인증 성공.
- 드래그: 일반 시험 10개 그룹, 빠른 세손가락 동작 관련 40개 시험 통과, 적용 대상이 아닌 조합 40개 확인.
- Mutter: 실제 컴파일·패키징·설치 완료. Ubuntu 일반 시험 177개 통과, 예상 실패 5개. 키맵 시험과 드래그 라이브러리 병용 10회 통과. 공개 동적 심볼과 설치 파일 무결성 검사 통과.

상세 근거와 당시 한계는 [원래 설치 보고서들](reports/README.md)에 있다. 이번 작업에서는 이미 검증한 Mutter 전체 컴파일·장시간 시험을 중복 실행하지 않고 소스 준비와 재설치/원복 경로를 확인했다. 새 Mutter 빌드 명령은 실행 시 원래 Debian 패키징의 시험을 수행한다.

## 남아 있는 실제 기기 검증

현재 GNOME은 아직 이전 Mutter 라이브러리를 메모리에 유지한다. 사용자가 작업을 저장한 뒤 재로그인해야 새 패치가 활성화된다. 그 뒤 한영 전환과 반복 잠금·지문 해제를 확인해야 한다. 다른 기기에서의 터치패드 동작·새 지문 등록·절전 후 인증은 해당 기기에서 별도 검증한다.

이번 작업에서 패키지 설치, 서비스 재시작, PAM 변경, 로그아웃·재부팅·절전은 수행하지 않았다.
