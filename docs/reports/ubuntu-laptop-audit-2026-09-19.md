### 확인된 문제 1: Intel 동영상 가속 드라이버 누락

시스템에 intel-media-va-driver와 intel-media-va-driver-non-free가 모두 없고, iHD_drv_video.so도 없다. 현재 시스템 라이브러리로 VA-API를 초기화하면 iHD/i965 드라이버를 찾지 못하고 실패한다. 이는 시스템 VA-API 경로에 대한 결과다. 자체 라이브러리를 포함하는 브라우저·샌드박스 앱의 실제 가속 여부까지 일괄 판정한 것은 아니다.

Ubuntu 공식 저장소의 다음 패키지를 작업 폴더에만 다운로드·추출해 시험했다.

- intel-media-va-driver 26.1.2+dfsg1-1
- libigdgmm12 22.9.0+ds1-1

별도 프로세스에서 이 임시 라이브러리를 사용하자 **vaInitialize=0(success)**, Intel iHD 26.1.2 로딩 및 H.264/HEVC/VP9/AV1 등의 프로파일 조회가 성공했다. 실제 동영상을 디코딩하거나 재생한 검사는 아니다.

따라서 우선 조치는 공식 패키지 intel-media-va-driver 설치와 설치 후 가속 재검증이다. 설치 시뮬레이션은 위 2개 신규 패키지, 삭제 0개다. 가속이 복구되면 소프트웨어 디코딩을 사용하던 앱의 CPU 부담과 전력 소모가 줄어들 수 있지만, 이번 검사에서 절감량을 측정하지는 않았다. [Intel 공식 드라이버 설명](https://github.com/intel/media-driver)

### 확인된 문제 2: 현재 지문 인식 사용 불가

센서는 EGIS/LighTuning ETU906Axx-E, USB ID 1c7a:05b1이다. USB 장치 자체는 인식되지만 설치된 fprintd의 GetDevices 결과는 빈 배열이다. libfprint의 공개 지원 목록에도 정확히 이 ID는 없다. 현재 소프트웨어 구성에서 지문 로그인을 사용할 수 없으며, 이것은 센서의 물리적 고장을 뜻하지 않는다. [libfprint 공식 지원 목록](https://fprint.freedesktop.org/supported-devices.html)

## 추가로 관찰된 경고

- BIOS/ACPI가 한 온도 영역에 잘못된 임계값을 제공한다: Invalid critical threshold (-274000), No valid trip points. 다른 CPU 온도 센서와 thermald는 동작하고 있으므로 전체 온도 제어 고장으로 단정하지 않는다.
- Intel HID power button 활성화 경고가 있다. 별도의 표준 ACPI Power Button은 등록되고 logind가 감시하므로 실제 전원 버튼 고장 여부는 직접 눌러 확인해야 한다.
- i915의 Selective fetch area calculation failed 로그가 부팅 시 1건 있다. 현재 3D 검사와 화면 연결은 정상이며, 이 기록만으로 화면 고장을 판정할 수 없다.
- GNOME 설정 호환 경고, 로그인 초기 Snap 서비스 재시작 등이 있었다. Snap 데스크톱 서비스는 후속 조회에서 running이고 현재 실패 서비스는 0개다.
- fwupdmgr에 업데이트가 표시되지 않았지만 LVFS 메타데이터 파일이 없으므로 BIOS가 최신이라고 판단할 근거는 부족하다. 제조사에서 이 모델의 BIOS 제공 여부를 별도로 확인해야 한다.

## 권장 후속 작업

1. 저장소 정보를 새로 받은 뒤 일반 시스템 업데이트를 적용한다. 단계적 배포로 보류된 항목을 억지로 강제할 필요는 없다.
2. intel-media-va-driver를 설치하고 시스템 VA-API 및 실제 사용하는 브라우저/동영상 앱의 가속을 재확인한다.
3. 작업을 저장한 상태에서 일반 절전 후 복귀를 시험한다. 화면, Wi-Fi, 터치패드, 소리가 복구되는지와 절전 성공 통계를 함께 확인한다.
4. 전원 어댑터를 분리하고 일정한 밝기와 작업 조건에서 배터리 방전율·온도를 측정한다. 현재 AC 연결 중 배터리의 0 W 표시는 노트북 총 소비전력이 0 W라는 뜻이 아니다.
5. 스피커·마이크·카메라, Bluetooth 주변기기, 필요한 외부 포트를 실제 사용해 확인한다.

확인된 누락과 제한을 보완하는 것이 우선이며, 현재 검사 결과만으로 Ubuntu 재설치를 권할 근거는 없다.

## 2026-09-19 시스템 업데이트 및 영상 드라이버 설치 결과

사용자의 설치 지시에 따라 Ubuntu 관리자 인증 후 수행했다. 저장소 목록 갱신, 일반 시스템 업데이트, 영상 드라이버 설치가 모두 종료 코드 0으로 완료됐다.

- 기존 시스템 패키지 31개 업데이트, 패키지 삭제 0개.
- intel-media-va-driver 26.1.2+dfsg1-1 및 libigdgmm12 22.9.0+ds1-1 신규 설치.
- 시스템 경로 /usr/lib/x86_64-linux-gnu/dri/iHD_drv_video.so 로딩 및 vaInitialize 성공. 임시 추출 라이브러리를 사용하지 않은 재검사다.
- H.264, HEVC, VP9, AV1 등을 포함한 드라이버 프로파일 조회 성공. 실제 동영상 재생 및 브라우저별 가속 사용 여부는 별도 검증 항목이다.
- dpkg --audit 이상 없음, APT 의존성 검사 통과.
- 시스템/사용자 실패 서비스 각각 0개. thermald, power-profiles-daemon, Bluetooth, NetworkManager, PipeWire, WirePlumber 실행 상태 정상. Wi-Fi 연결 유지.
- 재부팅 필수 표시 파일은 생성되지 않았다. 기존 브라우저·영상 앱은 완전히 종료한 뒤 다시 실행하여 새 드라이버를 사용하도록 한다.

Ubuntu 단계적 배포 정책으로 6개 패키지는 보류됐다: gir1.2-mutter-18, libmalcontent-0-0, libmalcontent-common, libmutter-18-0, mutter-common, mutter-common-bin. 설치 실패가 아니며, 강제 업데이트하지 않았다. 이 6개를 제외한 일반 upgrade 대상은 0개다.

지문 인식, 최대절전 구성 및 실제 절전·복귀 검증은 이번 패키지 설치로 해결되었다고 판정하지 않는다.

## 지문 센서 복구 가능성 추가 조사

기본 드라이버 미지원과 별개로, 정확히 같은 USB ID 1c7a:05b1을 지원 대상으로 추가한 비공식 드라이버를 찾았다: [likeablob/libfprint-fmv-etu906axx-e](https://github.com/likeablob/libfprint-fmv-etu906axx-e). 개발자는 Fujitsu FMV WU7-K3의 ETU906Axx-E 지원을 명시한다. 소스를 직접 확인했으며, 2026-02-04 커밋 e105528828a04dffde789cda48742c204183386d에서 해당 ID와 20단계 등록 설정을 추가했다.

이 포크는 SDCP 보안 통신 지원 분기를 기반으로 한다. 확인한 코드에서는 장치 인증서·서명 검증을 유지하고, 지문 등록 완료 응답이 오류이면 실패 처리한다. 일부 다른 공개 성공 사례에서 사용한 등록 오류 무시 패치는 적용하지 않았다. 이는 소스 일부 검토 결과이며 전체 보안 감사나 이 노트북에서의 동작 검증을 의미하지 않는다.

프로젝트 기반 버전은 1.94.9이며, 이 시스템의 기본 라이브러리는 1.95.1이다. Ubuntu 26.04에서 별도 빌드와 호환성 확인 후 장치 인식, 지문 등록, 일치/불일치 인증, 절전 후 복구를 시험하는 경로가 있다. 이 조사에서는 비공식 드라이버를 설치하거나 로그인 설정을 변경하지 않았다.

해당 프로젝트에는 [절전 후 지문 서비스가 중단되는 공개 보고](https://github.com/likeablob/libfprint-fmv-etu906axx-e/issues/2)가 있다. 보고 대상은 Fedora와 Samsung 1c7a:05a5이며, 이 Fujitsu 05b1에서도 발생한다고 단정할 수는 없다.

## 지문 드라이버 빌드·설치 및 실제 인증 결과

사용자의 빌드·적용 지시에 따라 위 고정 커밋을 egismoc 드라이버만 포함하도록 빌드했다. 단위 시험 3개 통과, Cairo 의존성이 필요한 이미지 조합 시험 1개는 건너뛰었다. Ubuntu 기본 라이브러리를 보존하고 /opt/fingerprint-egis-05b1/e105528에 설치했으며, fprintd 서비스에만 해당 라이브러리를 적용했다.

- 센서 1개 인식 및 오른쪽 검지 등록 완료(enroll-completed).
- 오른쪽 검지 인증 성공(verify-match), 등록하지 않은 왼쪽 검지 인증 거부(verify-no-match).
- fprintd 서비스 재시작 후 등록 목록 유지와 오른쪽 검지 인증 성공 확인.
- 인증서·서명 검사나 등록 오류 검사를 우회하는 패치는 적용하지 않았다.
- 기존 비밀번호 로그인 및 공통 PAM 인증 설정을 유지했다.

등록 시 저장 상태 표시 관련 드라이버 경고와 손가락 미접촉 시간 초과 뒤 취소 경고가 있었다. 사용자가 손가락을 대고 진행한 위 등록·인증 검사는 통과했다. 로그인 화면 자체와 절전·복귀, 전체 재부팅 후 동작은 아직 시험하지 않았다. 상세 설정, 경고 및 원복 절차는 [지문 드라이버 설치 보고서](./fingerprint-driver-installation.md)에 기록했다.
