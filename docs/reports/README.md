# 당시 작업 기록

이 디렉터리의 문서·스크립트는 2026-09-19 원래 작업의 기록이다. 시간순 상태 변화, 당시 계정명, Codex 작업 경로, GNOME PID, 이전 설치 경로가 남아 있다. 그 경로의 파일이 현재도 있다는 보장은 없다.

**실제 재설치·원복에는 저장소 루트의 `ubuntu-custom`, `admin-fingerprint`와 현재 README를 사용한다.** 이곳의 `.sh`·`.py`는 이력 확인용으로만 보관하며 실행 권한을 부여하지 않았다. 문서의 초기 점검 결과보다 후속 설치/검증 결과가 우선한다. 관리자 지문 PAM 설정은 최초 계획 단계에서 중단됐다가 이후 09:59 KST에 적용 완료했다. [현재 관리자 인증 안내](../admin-fingerprint.md)를 참고한다.
